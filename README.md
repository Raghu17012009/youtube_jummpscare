# Shorts Scream

A Manifest V3 extension for Brave, Chrome, and other Chromium browsers. It displays a stylised jump-scare whenever a user opens YouTube.

## Install in Web Browser

1. Open `brave://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked** and choose this folder.
4. Open the extension popup to tune the delay, duration, sound, and volume.

The scare fires once when entering YouTube. It can be dismissed with **Esc** or the on-screen button. Audio uses the Web Audio API, so Chromium can require a prior interaction with the YouTube tab before allowing playback.
